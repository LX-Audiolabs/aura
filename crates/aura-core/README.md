# aura-core

Host-facing plugin API for [AURA](https://github.com/LX-Audiolabs/aura):
`PluginLogic`, `AudioBuffer` / `BusLayout`, process context, shared state blob
(`encode_state` / `decode_state`).

Authors normally depend on the **`aura`** umbrella crate, not this crate alone.
